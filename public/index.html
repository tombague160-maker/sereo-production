⚠️ Zone dangereuse — Réinitialiser les bons de commande

À utiliser après une migration ou pour repartir propre avec un re-import

Cette action supprime définitivement :

  • ✗ Toutes les commandes (bons de commande)
  • ✗ Tous les clients
  • ✗ Toutes les ventes importées
  • ✗ Toutes les tournées de livraison

Et préserve :

  • ✓ Le stock (catalogue produits + quantités)
  • ✓ L'historique des mouvements de stock
  • ✓ L'historique des évènements
  • ✓ Les archives Excel (tu peux re-télécharger tes fichiers)
  • ✓ Tes paramètres visuels (thèmes, logo)

Après purge, va dans Historique des imports ci-dessus pour re-télécharger tes Excel et les ré-importer depuis le Tableau de bord.
