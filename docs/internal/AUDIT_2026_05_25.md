## 🔴 P0 — Bug confirmé et corrigé

### B3. Recovery SQLite corruption absent → **CORRIGÉ en v1.16.0** ✅

**Fichier** : `server.js` (`getSqliteStore`, `recoverCorruptSqliteStore`) + `storage/sqliteStore.js` (`PRAGMA quick_check`)

**Problème (prouvé par exécution)** : un fichier SQLite corrompu (octets garbage, ou header valide + corps cassé) faisait `throw Error: file is not a database` non géré → crash serveur, `/login` inaccessible.

**Fix livré** :
- `getSqliteStore()` wrappe l'ouverture en try/catch → `recoverCorruptSqliteStore()` : quarantaine du fichier corrompu → restore du backup gzip le plus récent (boucle, valide chacun) → sinon base vierge.
- `createSqliteStore` ajoute un `PRAGMA quick_check` pour détecter la corruption **silencieuse** (header valide + corps cassé qui ne throw pas à l'ouverture).
- `test/corruption.test.js` : 3 modes (garbage / tronqué / vide) prouvent crash avant et recovery après. **130/130 tests passent.**

### B2. Backtrack `pret_livraison → en_preparation` — **MEDIUM, décision produit requise**

**Fichier** : `server.js:189` (`ORDER_STATUS_TRANSITIONS`)

**Confirmé par exécution** : la transition est acceptée (HTTP 200). **Mais** un opérateur peut légitimement vouloir corriger une préparation. À trancher : interdire (rigueur ERP) vs garder (souplesse terrain). **Pas un bug certain.**

## 🟡 P2 — Polish & dette (backlog)

### Métier

- **Recherche stock** : highlight des résultats matchés (UX)
- **Quick edit inline stock** : input direct au lieu de boutons +1/+5 répétés
- **Vue tableau dense stock** : 30 produits visibles d'un coup
- **Sélection multi Bons de commande** : actions groupées
- **Prévisualisation import Excel** : voir le diff avant de committer
- **Drag & drop** dans Préparation kanban (4 colonnes) — overkill probable
- **Stop status "en_attente"** : pause dans la tournée sans clore le client
- **Bons sans clients orphelins** : nettoyage périodique
- **Audit log par utilisateur** : `createdBy` toujours "local" actuellement

### Tech

- **Cache in-memory DB** : éviter `readDb()` à chaque requête
- **UPSERT par diff** : éviter wipe-and-replace SQLite à chaque writeDb
- **Bundle minification** : `app.js` 144 KB → ~40 KB gzip
- **Virtualisation listes** > 5000 items (`renderCommandesLivrees`)
- **Suppression code mort JSON** dans sqliteStore.js (~100 LOC legacy)
- **Index `lignes_commande(commande_id)`** (FK manquant)
- **Validation centralisée Zod** (au lieu de checks manuels dispersés)
- **CSP `upgrade-insecure-requests`** + HSTS si HTTPS
- **API versioning** `/api/v1/` pour future breaking change

### Design system

- **Échelle spacing cohérente** : 4/8/12/16/24/32 (au lieu de valeurs arbitraires)
- **Échelle typo** : xs/sm/base/lg/xl/2xl avec line-height harmonisé
- **Breakpoints standardisés** : 640 / 1024 / 1400 (au lieu de 380/480/520/720/820/1100)
- **Composants `.button--variant`** au lieu de `.context .button` (lourde spécificité)
- **Suppression dead CSS** : `.nav-badge`, `.workflow-card`, etc.

### A11y

- **Touch targets** 44×44 px partout (déjà fait sur les filtres, à étendre)
- **`aria-hidden="true"`** systématique sur SVG décoratifs
- **Mode "haute densité"** : option pour réduire paddings de 30%
